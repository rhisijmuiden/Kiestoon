# Sneltoetscodes

Kies deze codes op elke telefoon of softphone. Ze werken op elk merk hetzelfde, en het portaal toont het resultaat
meteen (bijvoorbeeld de stand van niet storen). De lijst staat ook op de pagina **Belfuncties & fraude**.

| Code | Wat het doet |
| --- | --- |
| `*97` | Je voicemail beluisteren |
| `*98` | Een willekeurige voicemailbox beluisteren (vraagt nummer en pincode) |
| `*43` | Echotest: hoor jezelf terug, om de audio te controleren |
| `*72<nummer>` | Alle gesprekken doorschakelen naar een nummer |
| `*73` | Doorschakelen stoppen |
| `*74<nummer>` | Doorschakelen naar een nummer aan of uit (wat een doorschakeltoets doet) |
| `*76` | Niet storen aan of uit |
| `*45` | Aan- of afmelden bij al je wachtrijen |
| `*45<wachtrij>` | Aan- of afmelden bij één wachtrij, bijvoorbeeld `*45700` |
| `*8` | Een gesprek opnemen dat in je opnamegroep overgaat |
| `**<toestel>` | Een gesprek opnemen dat op dat toestel overgaat, bijvoorbeeld `**203` |
| `70` | Het gesprek parkeren (doorverbinden naar 70); je hoort de parkeerplaats |
| `71` … `79` | Een geparkeerd gesprek oppakken van die plaats |
| `*80<toestel>` | Intercom: het andere toestel neemt op via de luidspreker |
| `*33<toestel>` | Supervisors: meeluisteren met het wachtrijgesprek van dat toestel |
| `*34<toestel>` | Supervisors: de medewerker influisteren (alleen de medewerker hoort je) |
| `*35<toestel>` | Supervisors: inbreken op het wachtrijgesprek |
| `*1` | Opname starten of stoppen tijdens een gesprek (als opnemen "op verzoek" staat) |
| `*28<id>` | Een tijdconditie wisselen tussen dag en nacht (het id staat bij de tijdconditie) |
| `*2` | Doorverbinden met ruggespraak tijdens een gesprek |
| `##` | Direct doorverbinden tijdens een gesprek |
| `112`, `911` | Noodnummers, altijd toegestaan |

!!! note "Parkeren gebruikt de 7-reeks"
    Gesprekken parkeren gebruikt `70` en `71`-`79`. Daarom beginnen wachtrijen bij 700 in het 3-cijferige plan, en
    kan een gekoppeld systeem het voorvoegsel 7 niet gebruiken.

Intercom (`*80` of een intercomtoets) bereikt alleen bekende toestellen die vrij zijn en niet op niet storen staan.
Hoe een telefoon opneemt (automatisch, met een waarschuwingstoon, met de microfoon uit, of ook tijdens een gesprek)
stel je per telefoon in, zie [Toetsen en uitbreidingsmodules](phone-keys.md#intercom).
